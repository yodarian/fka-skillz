# FKA Skillz

Zentrales Repository für wiederverwendbare Skills, Agents und Prompts für KI-Tools (Copilot und mehr).

## Struktur

```
fka-skillz/
├── .github/
│   ├── copilot-instructions.md
├── .agents/                  # Copilot Agents
├── laravel/                  # Test-Laravel Projekt
├── docs/                     # Dokumentation
└── README.md
```

## Komponenten

- **Agents** (`.agents/`): Spezialisierte KI-Agenten mit spezifischen Workflows
- **Skills** (`.agents/skills/`): Wiederverwendbare Funktionsmodule für KI-Agents
- **Test-Laravel** (`/laravel`): Testumgebung für Skill-Validierung (später löschbar)

## Verwendung

### Mit Copilot
Skills und Agents werden automatisch von Copilot erkannt und geladen.
